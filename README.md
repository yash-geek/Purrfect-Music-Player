# Purrfect Music Player

Purrfect Music Player is a personal, web-based music player developed out of interest. This project is a frontend-only application built using **HTML**, **CSS**, and **JavaScript**, and is deployed for easy access on the web.

## 🎵 Features

- Play, pause, and skip tracks
- Interactive and responsive UI

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript

## 📦 Getting Started

To run this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/yash-geek/Purrfect-Music-Player.git
   ```
2. Open `index.html` in your browser.

_No build step is required since this is a static frontend project._
_Run using live server._
